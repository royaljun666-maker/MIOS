# 내 투자 비서

여러 증권사 계좌를 한곳에 모아 보고, 시세·뉴스·무료 AI 분석을 받는 앱입니다.

## 내려받기 (v1.8)

| 기기 | 받기 |
|---|---|
| 📱 안드로이드 폰 | [myfin_v1.8.apk 받기](https://github.com/royaljun666-maker/MIOS/raw/main/myfin_v1.8.apk) |
| 💻 Windows PC | [AssetAssistant_PC_v3.4.zip 받기](https://github.com/royaljun666-maker/MIOS/raw/main/AssetAssistant_PC_v3.4.zip) |

**폰 설치:** 링크를 눌러 받은 뒤 파일을 열고 설치. "출처를 알 수 없는 앱" 허용을 물으면 허용해 주세요.
이미 예전 버전이 있으면 지우지 말고 그대로 설치하면 정보가 유지됩니다.
v1.6 이상은 화면·기능 업데이트를 앱이 자동으로 받아요. v1.8부터는 받자마자 그 자리에서 적용돼요.

**PC 설치:** zip을 오른쪽 클릭 → 압축 풀기 → `설치하기.bat` 두 번 클릭.

> ⚠️ 이 저장소의 `update.json`은 앱의 업데이트 확인·사용 관리 파일입니다. 지우거나 저장소 이름을 바꾸면 모든 앱이 멈춥니다.
